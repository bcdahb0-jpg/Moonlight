目标：帮做一个番茄钟html格式的
结果：番茄钟已创建完成：`/workspace/pomodoro-timer.html`，用浏览器直接打开即可使用。

**功能一览：**

- 🍅 **三阶段模式**：专注 / 短休息 / 长休息，顶部标签一键切换
- ⏱ **环形倒计时**：圆形进度条实时显示剩余时间，颜色随模式变化（红=专注、绿=短休、蓝=长休）
- ▶️ **控制按钮**：开始/暂停、重置、跳过当前阶段
- 🔄 **自动流转**：每完成 4 个番茄自动进入长休息，其余进入短休息
- ⚙️ **可自定义时长**：专注/短休/长休分钟数均可调整（1–120 分）
- 🔔 **完成提醒**：阶段结束时蜂鸣提示 + 弹窗（首次点击需先点一下页面以解锁音频）
- 📊 **统计持久化**：当日及累计完成的番茄数保存在浏览器 localStorage，刷新不丢失
- 📱 **响应式**：手机和电脑都能用；切后台再回来会自动校准倒计时

打开后点「开始专注」即可进入状态。需要调整配色、加白噪音、或改成别的交互方式，随时说。
工具轨迹：ls, write_file
