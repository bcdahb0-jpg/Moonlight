目标：是做一个番茄钟html格式的
结果：已完成 ✅ 番茄钟已生成：**`/workspace/pomodoro.html`**

单文件、零依赖，浏览器直接打开即可使用。

**功能一览：**
- 🍅 **三种模式**：专注（默认 25 分钟）/ 短休息（5 分钟）/ 长休息（15 分钟），可点击顶部标签手动切换
- ⏱ **环形进度**：SVG 圆环实时显示剩余比例，背景色随模式自动变化（红/绿/蓝）
- ▶️ **控制按钮**：开始 / 暂停 / 重置
- 🔁 **自动流转**：专注结束自动进入休息并响铃提示；每完成 4 个番茄自动进入长休息
- ⚙️ **自定义时长**：专注、短休、长休时长均可调整（输入后自动生效）
- 📊 **完成统计**：今日完成番茄数 + 本轮 4 点进度圆点
- 🔔 **提示音**：Web Audio 合成的四音提示音（无需音频文件）
- 💻 **标签页同步**：浏览器标题实时显示剩余时间与模式

需要调整样式配色、增加"自动开始下一个"开关或加入本地存储（刷新后保留今日统计）的话，随时说。
工具轨迹：ls, write_file
