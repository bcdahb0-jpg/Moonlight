目标：帮我做一个番茄钟
结果：✅ 番茄钟已完成，生成文件 `pomodoro-timer.html`，双击用浏览器打开即可使用。

**功能一览：**

- 🍅 **三种模式**：专注 / 短休息 / 长休息，顶部标签一键切换
- ⏱️ **圆形进度环**：时间流逝可视化，倒计时精确到秒
- ▶️ **控制**：开始 / 暂停 / 继续 / 重置，支持快捷键（空格 = 开始暂停，R = 重置）
- 🔔 **智能流转**：专注结束自动进入休息；每完成 4 个番茄自动进入长休息（可自定义间隔），休息结束回到专注
- 📊 **今日统计**：记录完成的番茄数和累计专注分钟数
- ⚙️ **可配置**：专注、短休、长休时长及长休间隔均可在底部修改
- 🎵 **提示音**：用 Web Audio 合成的叮咚声，无需音频文件；并支持系统桌面通知（首次使用时浏览器会询问权限）
- 🌙 **深色主题**：专注为橙色、休息自动切换为绿色

浏览器打开后点击一下页面再点"开始"（浏览器要求用户交互后才能播放声音），即可开始专注。需要再加功能（比如本地持久化记录、白噪音、待办清单）随时告诉我。
工具轨迹：ls, write_file, glob
