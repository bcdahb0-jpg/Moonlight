目标：做一个番茄钟html格式的
结果：已创建番茄钟页面 **`/workspace/pomodoro.html`**，浏览器直接打开即可使用。

**功能一览：**

| 功能 | 说明 |
|---|---|
| 🍅 番茄计时 | 默认专注 25 分钟 / 休息 5 分钟，倒计时圆环动画 |
| ▶ 开始 / ⏸ 暂停 / ↺ 重置 | 三个控制按钮，空格键也可快捷开始/暂停 |
| 🔄 自动切换 | 专注结束自动进入休息，休息结束自动开始下一轮 |
| ⚙️ 自定义时长 | 专注、休息分钟数均可设置，点击「应用设置」生效 |
| 📊 完成统计 | 今日完成番茄数，存于浏览器本地（刷新不丢） |
| 🔔 提示音 | Web Audio 合成三声提示音，无需外部音频文件 |
| 📱 响应式 | 适配手机与电脑，深色渐变风格 |

**使用方式：** 双击打开 `pomodoro.html`（或拖入浏览器）即可。
