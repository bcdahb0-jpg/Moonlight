目标：在当前工作目录创建一个番茄钟（Pomodoro Timer）的 HTML 文件，文件名建议 pomodoro.html。要求：单文件、纯 HTML+CSS+JavaScript，包含 25 分钟工作计时和 5 分钟休息计时切换、开始/暂停/重置按钮、倒计时显示、完成一次番茄后自动提示。界面简洁美观，中文界面。创建后返回文件完整路径和文件内容摘要。
结果：✅ 已创建番茄钟单文件。

**完整路径**：`/workspace/pomodoro.html`（约 9.6 KB）

**文件内容摘要**：

- **技术**：纯 HTML + CSS + JavaScript，零外部依赖，单文件可直接双击浏览器打开
- **计时**：工作 25 分钟 / 休息 5 分钟，顶部 tab 手动切换；倒计时基于时间戳计算（非简单累减，长时间运行不漂移）
- **倒计时显示**：SVG 环形进度条 + 中央大号 MM:SS 数字 + 当前模式标签，标签页标题同步实时更新
- **控制按钮**：开始/暂停（同一按钮切换状态）、重置（环形按钮 ↺）
- **完成提示**：计时结束时三重提示——顶部 Toast 弹窗、Web Audio API 生成的 3 声提示音、浏览器桌面通知（首次点击开始自动请求权限）
- **自动切换**：完成一个番茄后自动切到休息模式、休息结束自动切回工作模式（不自动开始，由用户点击开始）
- **界面**：中文界面，卡片式设计；工作模式番茄红 / 休息模式清新绿双主题配色，按钮、进度环、背景色随模式平滑过渡

**核心交互流程**：点「开始」倒计时 → 25 分钟结束响铃 + Toast + 通知 → 自动切到休息 5 分钟 → 休息结束响铃并切回工作，循环往复。
工具轨迹：write_file
