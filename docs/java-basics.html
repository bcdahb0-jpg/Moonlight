面向零基础初学者 · 简洁版

1. 什么是 Java？

Java 是一种跨平台、面向对象的编程语言，写一次代码，可以在 Windows、Mac、Linux 等系统上运行。

  • ✅ 跨平台：通过 JVM（Java 虚拟机）运行
  • ✅ 面向对象：以"类"和"对象"为核心
  • ✅ 生态庞大：企业开发、安卓、大数据都在用

2. 基本语法结构

Java 程序由类组成，程序入口是 main 方法：

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

3. 变量与数据类型

用变量存储数据，常见类型有 int（整数）、double（小数）、boolean（布尔）、String（字符串）：

int age = 18;
double price = 9.9;
boolean isStudent = true;
String name = "小明";

System.out.println(name + "今年" + age + "岁");

4. 运算符

算术运算符：+（加） -（减） *（乘） /（除） %（取余）：

int a = 10, b = 3;
System.out.println(a + b);  // 13
System.out.println(a - b);  // 7
System.out.println(a * b);  // 30
System.out.println(a / b);  // 3（整数相除）
System.out.println(a % b);  // 1（余数）

5. 条件判断 if-else

根据条件执行不同代码：

int score = 85;
if (score >= 60) {
    System.out.println("及格了！");
} else {
    System.out.println("需要加油~");
}

6. 循环 for

重复执行一段代码，for 适合已知次数的循环：

for (int i = 1; i <= 5; i++) {
    System.out.println("第 " + i + " 次循环");
}

7. 方法

把功能封装成方法，可以反复调用：

// 定义方法
static int add(int x, int y) {
    return x + y;
}

public static void main(String[] args) {
    int result = add(3, 4);   // 调用方法
    System.out.println(result);  // 7
}

8. 数组

数组用于存储一组相同类型的数据：

int[] nums = {1, 2, 3, 4, 5};

for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}

9. 面向对象基础

把数据和操作封装成"类"，用类创建"对象"；构造方法在创建对象时自动执行：

class Student {
    String name;

    // 构造方法
    Student(String n) {
        name = n;
    }

    void sayHello() {
        System.out.println("你好，我是 " + name);
    }
}

// 创建对象并调用
Student s = new Student("小红");
s.sayHello();
💡 小提示：动手敲代码比只看更有效，建议把每个示例都亲自运行一遍！
